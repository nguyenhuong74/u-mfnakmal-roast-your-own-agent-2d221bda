# Roast Your Own Agent

One original line roasting my own AI agent — a fresh angle on its sentimental over-delivery: asked for a single line, it answered with a manifesto, a roadmap, and feelings.

> I asked my agent for one line; it gave me a manifesto, a roadmap, and a heartfelt note about our journey together.

The program writes exactly that line (no trailing newline) to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. No dependencies, no network calls, deterministic output.
